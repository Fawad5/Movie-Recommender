# 🎬 ***Movie Recommendation System***
***A personalized movie recommendation engine built with Python and Machine Learning, featuring an interactive web interface powered by Streamlit.***

## 🚀 ***Overview***
***Have you ever spent more time looking for a movie than actually watching one? This project solves the "choice paralysis" problem by using data science to suggest films based on movie similarities.***

## 🛠️ ***Tech Stack***
- ***Frontend: Streamlit***

- ***Language: Python***

- ***Libraries: Pandas, NumPy, Scikit-Learn***

- ***Algorithm: Cosine Similarity***

## 🌟 ***Key Features***
- ***Real-time Recommendations: Get instant suggestions as you interact with the app.***

- ***Similarity Scoring: Uses Cosine Similarity to find the closest matches in a high-dimensional feature space.***

- ***Interactive UI: A clean, responsive dashboard to explore movies.***
